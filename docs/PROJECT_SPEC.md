# Project Specification — aether-ai-ui-components

## Purpose
Accessible reusable UI components, theme tokens, layout primitives, and interaction patterns.

## Scope
- Design tokens, component props, accessibility contract, keyboard behavior, theming, visual fixtures, and versioning.
- Provide consistent presentation-only primitives with documented accessibility behavior.
- Keep domain data fetching, authentication, authorization, and business rules outside this repository.

## Acceptance criteria
- Components have typed props and keyboard/screen-reader behavior documented.
- Unsafe URLs and raw HTML are rejected or sanitized.
- Visual and accessibility regressions have repeatable tests.

## Status
Documentation only; no UI source, package manifest, tests, or CI workflow was found in the inspected default-branch tree.
