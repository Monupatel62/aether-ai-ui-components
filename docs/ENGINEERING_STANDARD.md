# Engineering Standard — aether-ai-ui-components

- Keep components accessible by default and document keyboard/focus behavior.
- Validate URL protocols and sanitize rich content; avoid unsafe HTML by default.
- Use typed props, stable public APIs, and documented deprecation policy.
- Keep presentation components free of product-domain and authorization logic.
- Test keyboard navigation, screen-reader labels, focus trapping/restoration, loading/error states, and safe URLs.
- Use visual regression fixtures that contain no customer data.
- Do not claim accessibility conformance without automated and manual verification.
