# Dependencies and Contracts — aether-ai-ui-components

## Dependency boundary
No product-domain dependencies; presentation primitives only.

## Public component contracts
- Typed props and documented defaults, states, events, and accessibility attributes.
- Explicit theme/token compatibility and deprecation policy.
- No hidden network requests or direct access to product-specific services.
- Safe handling of user-provided text, links, and rich content.

## Compatibility
Breaking prop or styling changes require a major release or migration note and consumer impact review.
