# Technical Design — aether-ai-ui-components

## Proposed structure
Tokens/theme, primitives, interaction components, icons, accessibility helpers, and test fixtures.

## Component requirements
- Explicit accessible name and state where applicable.
- Keyboard operation and predictable focus placement/restoration.
- Safe URL protocol validation and no unsanitized HTML by default.
- Controlled/uncontrolled behavior documented for inputs.
- Loading, disabled, error, and confirmation states exposed semantically.

## Open decisions
Framework, styling system, package format, browser support matrix, and visual-test tooling require ADRs.
